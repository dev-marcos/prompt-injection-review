# Prompt Injection in LLM-based NER Systems

Repository containing the search strategies, bibliographic data,
scripts and processing pipeline used in a systematic/scoping review
on prompt injection attacks in Large Language Model-based
Named Entity Recognition and Information Extraction systems.

## Databases

The following databases are currently included:

- ACM Digital Library
- IEEE Xplore
- ScienceDirect
- SpringerLink

## Repository structure

```text
searches/       Database-specific search strategies and downloaders
data/raw/       Original database exports
data/merged/    Merged bibliographic data
data/deduplicated/ Deduplicated references
scripts/        Data processing scripts
protocol/       Review methodology and search protocol
docs/           Search logs and documentation
